# موقع ⁦مطعم .S. الغدير⁩

موقع عربي ثابت مبني بـ React وJavaScript وCSS. يشمل ٥ صفحات عامة و٨٢ صفحة صنف مستقلة، وسلة محلية تجهّز مسودة الطلب في واتساب على الرقم `0501083083`.

## التشغيل

يتطلب المشروع Node.js 20.19 أو أحدث. من جذر المشروع بعد فك الملف شغّل:

```bash
npm ci
npm run dev
```

ملفات `dist/` المرفقة نسخة جاهزة للمعاينة. لتجربتها محلياً بعد تثبيت الحزم:

```bash
npm run preview
```

## تجهيز نسخة النشر

١. عدّل بيانات الفرع وروابط التواصل في `src/config.js`، وراجع الأسعار ومقاسات الوجبات في `src/menu-data.json`. صفحة الفرع تفتح موقع المطعم في خرائط Google.

٢. اضبط عنوان موقع الإنتاج الكامل وأعد البناء. استبدل نطاق المثال بنطاق المطعم:

```bash
SITE_URL=https://restaurant.example npm run build
npm run verify
```

في Windows PowerShell:

```powershell
$env:SITE_URL = 'https://restaurant.example'
npm run build
npm run verify
```

٣. ارفع محتويات `dist/` إلى جذر استضافة ثابتة تدعم ملفات `index.html` داخل المجلدات. استخدم `404.html` لصفحة الخطأ. اجعل أمر البناء `npm run build` ومجلد النشر `dist` إذا كانت الاستضافة تبني من مستودع. أضف `SITE_URL` إلى إعدادات بيئة البناء.

٤. بعد ربط النطاق وتفعيل HTTPS، جرّب روابط المنيو والأصناف مباشرة، ثم أرسل خريطة الموقع إلى Google Search Console. البناء من دون `SITE_URL` يطلب من محركات البحث عدم فهرسة نسخة المعاينة.
